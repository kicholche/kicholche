# Kicholche Design Baseline

The supplied reference image contains two separate designs.

Desktop is the left-side layout.
Mobile is the right-side phone layout.

Desktop must keep its own header, navigation, hero/news grid, sidebar, cards and footer.
Mobile must keep its own compact header, hero, category icons, cards and bottom navigation.

Do not turn desktop into a scaled mobile layout.
Do not inject mobile navigation into desktop.
Do not change one layout while fixing the other unless a shared primitive truly requires it.

The supplied Kicholche logo is the primary brand asset.
